Spelling dictionaries and lists of common slips, used by beeref/spelling.py.

Dictionaries (Hunspell), from https://github.com/LibreOffice/dictionaries
  pt_PT.aff, pt_PT.dic  Portuguese (Portugal), Natura project, Universidade
                        do Minho. GPL 2 / LGPL 2.1 / MPL 1.1. See README_pt_PT.txt.
  en_GB.aff, en_GB.dic  English (United Kingdom), Marco A.G. Pinto. LGPL.
                        See README_en_GB.txt.
  en_US.aff, en_US.dic  English (United States), SCOWL, Kevin Atkinson.
                        BSD-style. See README_en_US.txt.

Lists of common slips, from LibreOffice
(https://github.com/LibreOffice/core, extras/source/autocorr/lang/<language>/DocumentList.xml),
under the Mozilla Public License 2.0:
  autocorrect_pt-PT.xml, autocorrect_en-GB.xml, autocorrect_en-US.xml

The files are as published, renamed only. Read by spylls
(https://github.com/spylls/spylls, MPL 2.0), a Hunspell written in Python.
